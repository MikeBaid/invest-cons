# Эксплуатационные скрипты

Здесь размещаются небольшие повторяемые команды диагностики и импорта. `preview_portfolio_classification.py` читает сохраненный PostgreSQL-снимок и явно переданный старый маппинг, не меняя их. Актуальные команды перечислены в `docs/commands.md`. Скрипты не должны содержать токены, DSN, персональные пути и бизнес-формулы.
