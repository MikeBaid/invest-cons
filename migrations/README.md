# Миграции схемы

Целевое место для версионированных миграций PostgreSQL. Сейчас каталог не содержит выполняемых миграций: схема `portfolio_v2` создается DDL в `src/portfolio_v2/storage.py`. Не запускайте этот каталог как механизм обновления базы.

При переносе: миграции меняют только схему; импорт/исправление учетных данных - отдельная идемпотентная команда. Проверять новую БД, обновление существующей БД и восстановление из backup. Не удалять старый DDL до подтвержденного перехода.
