# Архитектурные решения (ADR)

Здесь фиксируются только решения, которые меняют модель данных, границы модулей, методику расчетов, безопасность или эксплуатацию. Один файл - одно решение, например `0001-account-identity.md`. Не использовать ADR для списка задач.

Шаблон: **контекст**, **решение**, **альтернативы**, **последствия**, **дата и статус** (`proposed`, `accepted`, `superseded`). При замене решения сохранять прежний документ и ссылку на новый. Первые ADR разумно посвятить идентичности инструмента между брокерами, политике версионирования расчетов и классификации денежных потоков Freedom после подтверждения фактических данных.
