# Критерии завершения задачи (DoD)

Задача считается завершенной, когда выполнены применимые пункты. Неприменимость пункта объясняется в описании изменения. Статус `implemented` не равен `verified` на реальных данных.

## Изменение кода

- Поведение и граница модуля описаны; нет копии существующей учетной формулы или скрытого знания о другом брокере.
- Новые изменяемые правила вынесены в проверяемый конфиг; секреты не добавлены в код, документацию, тестовые фикстуры или логи.
- Учтены `Decimal`, дата/часовой пояс, исходная валюта, отсутствие данных и неполное покрытие счетов.
- Для изменения схемы есть версионированная миграция, проверены чистое применение и обновление существующей БД. Новые таблицы не создаются неучтенным DDL при каждом старте.
- Логи позволяют восстановить этап и причину сбоя по ID запуска, но не раскрывают учетные и персональные данные.

## Проверка

- Есть unit-тесты финансовых инвариантов и граничных случаев; контрактные тесты адаптера используют обезличенные ответы брокера; изменения БД имеют интеграционный тест на PostgreSQL.
- Повторный запуск не создает двойных операций и не меняет исторические снимки. Ошибка брокера/FX явно ухудшает качество данных.
- Проверены тестовый набор целиком и затронутые команды CLI/бота. Отдельно указано, что не удалось проверить.
- Для метрик, появляющихся у пользователя, есть сверка с источником и записанный результат по [протоколу](testing.md). Пока сверка не завершена, статус только `implemented`.

## Документация и выпуск

- Обновлены спецификация/контракт, [статус](status.md), [команды](commands.md) и эксплуатационные шаги, если они изменились.
- Существенное архитектурное решение сопровождается ADR с альтернативами и последствиями.
- Приемочный результат указывает период, счета, источник, версию расчета и известные ограничения.
- Перед выпуском: тесты, проверка diff на секреты, миграция на чистой БД, запуск из документированных команд, план отката и актуальная резервная копия.

Для первого релиза дополнительно обязательны проверенная авторизация по владельцу и сверка по обоим брокерам. Пока это не сделано, весь релиз не помечается `verified`, даже если отдельные функции работают.
