# Конфигурация бизнес-правил

Здесь находятся черновики будущих версионируемых политик. Первый файл - [IPS personal_main](ips/personal_main.draft.yaml). В первом техническом срезе runtime-policy еще нет; наличие каталога не означает ее поддержку.

Секреты, DSN, Telegram token и брокерские ключи здесь не хранятся. Они задаются через окружение/секретное хранилище. Не выносить в конфиг математические инварианты и поля протоколов. При применении политики сохранять ее версию в результате расчета.
