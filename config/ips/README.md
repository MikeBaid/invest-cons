# Черновики инвестиционной политики

`personal_main.draft.yaml` фиксирует согласованную иерархию и предварительные веса. Свободные 4% внешнего контура добавлены к `external.bonds.kz_fx`: его цель теперь 4%, а `external.bonds` - 15%. Статус IPS остаётся `draft`; отчёт может показывать фактические доли и черновые ориентиры, но не должен считать их утверждённой рекомендацией. `legacy_mapping_preview.yaml` используется только для пробной сверки со старым маппингом. Подтверждённые фактические назначения версионируются в `portfolio_v2.classification_history`; команды просмотра и импорта описаны в [commands.md](../../docs/commands.md). `portfolio_exclusions.yaml` исключает утверждённые счета и `non-tradeable` из инвестиционного NAV, доходности и выплат, не меняя сырой брокерский факт.

Перед активацией необходимо утвердить веса, допустимые диапазоны, параметры оценки риска, основу доходности до/после налогов и состав счетов. Валидатор должен проверять сумму целей детей на каждом уровне, непересечение конечных направлений и соответствие версии состава счетов.
